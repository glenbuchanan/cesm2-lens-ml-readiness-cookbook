Splitting by ensemble member

This is the step this cookbook changes from Unidata’s notebooks, which split “randomly”. Here the unit of the split is the ensemble member, and the cost of getting it wrong is measured rather than assumed.

Overview¶

  1. Load the table with the test members of chapter 2 already named per forcing half.

  2. Build member-grouped validation folds over the training members, and verify that no member sits on both sides of any fold.

  3. Measure the dependence that would make a member-blind split leak: within members (lag-1) and between micro-siblings.

  4. Score one model three ways — this cookbook’s pipeline, transforms fit before the split, and a member-blind split — and read the gaps.

Shared code lives in lensml.py beside the chapters (parameters, transforms, ladder, scoring, paired test, register); show() prints a function’s source where a chapter introduces it.

Why the member is the unit¶

scikit-learn’s guidance on grouped cross-validation: “all the samples in the validation fold come from groups that are not represented at all in the paired training fold.” Three reasons make the member the group:

  1. The question is about members never seen. The score has to come from a realisation the model has not met; a member-blind split scores new years of members it already knows.

  2. The transforms. The forced curve and the wet threshold are refit on each fold’s training members (score_splits calls fit_transforms per fold). Fit before the split, held-out winters would help fit the curve and threshold that label them — the same leak as a StandardScaler fit on the whole table.

  3. Dependence is measured, not assumed. Rodgers et al. 2021 §2.2 is why WINDOW starts late, but they give no figure for how much initial-condition memory is left after fifty years. The next cell prints the lag-1 autocorrelation inside each member, then the correlation between micro-siblings (members sharing a start year, as the CESM2 LE project page defines them — the i1231-style token in member_id) and between unrelated members, with a line that fails if siblings share more. Siblings are not grouped in the split; that line is what licenses it.

Two splits are made, both by member, both from the declared seed: the test members (chapter 2) and member-grouped folds over the rest, N_FOLDS = min(N_FOLDS_MAX, training members). The folds are stratified on the all-training labels, which decide only which members share a fold; the labels scored inside a fold are refit on that fold’s training members.

The leak contrast: one model, three ways¶

One function scores every validation run in this cookbook. With refit_transforms=True it refits the forced curve and wet threshold on each fold’s training rows; with False it uses the columns fit once on all training members, before the folds.

B differs from A only in where the transforms are fit; C differs from A only in the split unit. The model is gradient boosting (chapter 4) at the base-rate decision threshold, so that it calls wet. The cell’s first line scores the same model at scikit-learn’s default 0.5 and prints how rarely it calls wet there: a precision resting on a handful of calls makes any gap a non-test, so below one wet call per hundred winters the cell marks the gaps NON-TEST. Each arm prints its scores with per-fold SDs and its wet-call count, then its gaps against A with the SD of the per-fold gaps — a rough scale; chapter 5’s paired test is the measurement.

Note what this cell is, for chapter 5: a validation score for boosting at the base-rate threshold, on the same seeds chapter 5 uses. Once it has been read, a trial of that model is no longer a blind one.

CONTRAST_THRESHOLD = 1 - WET_QUANTILE  # the designed base rate
MIN_WET_CALL_SHARE = (
    0.01  # below this, precision and recall gaps are a NON-TEST
)


def contrast_model(seed):
    return FixedThresholdClassifier(
        GradientBoostingClassifier(**BOOSTING_SETTINGS, random_state=seed),
        threshold=CONTRAST_THRESHOLD,
        response_method="predict_proba",
    )


arms = {
    "A member split, transforms refit in each fold   ": dict(
        runs=[], cm=np.zeros((2, 2), dtype=int)
    ),
    "B member split, transforms fit before the split ": dict(
        runs=[], cm=np.zeros((2, 2), dtype=int)
    ),
    "C member-blind split, transforms refit in fold  ": dict(
        runs=[], cm=np.zeros((2, 2), dtype=int)
    ),
}
_s05, _cm05 = score_splits(
    GradientBoostingClassifier(**BOOSTING_SETTINGS, random_state=RNG_SEED),
    train,
    list(member_folds(RNG_SEED, N_FOLDS).split(X_tr, y_tr, g_tr)),
    refit_transforms=True,

for rep in range(S.n_repeats_effective):
    seed = RNG_SEED + rep
    by_member = list(member_folds(seed, N_FOLDS).split(X_tr, y_tr, g_tr))
    shuffled = StratifiedKFold(
        n_splits=N_FOLDS, shuffle=True, random_state=seed
    )
    by_year = list(
        shuffled.split(X_tr, y_tr)
    )  # member-blind: winters shuffled
    plan = [(by_member, True), (by_member, False), (by_year, True)]
    for (label, store), (splits, refit) in zip(arms.items(), plan):
        s, cm = score_splits(
            contrast_model(seed), train, splits, refit_transforms=refit
        )
        store["runs"].append(s)
        store["cm"] += cm

    return v.std(ddof=1) if len(v) > 1 else 0.0

Why the gaps are small here¶

Read each arm’s gap vs A line against the SD printed beside it. On this table the leaks barely bite, for three reasons the printed lines show:

  • No within-member persistence to memorise. The mean: line under the lag-1 table gives lag1_wet near zero: one wet winter says almost nothing about the next in the same member, so a member-blind split (arm C) has little to learn from a member’s other years. The input’s lag-1 is negative, not positive — no run of similar autumns either.

  • The input carries no member identity. With one detrended Niño 3.4 value per winter, nothing in a row tells the model which member it came from, so it cannot memorise a member even when it has seen one.

  • The transforms are smooth fits to many members. A cubic in year through the mean of many training members, and one pooled quantile, barely move when one fold’s members are left out — so fitting them before the split (arm B) leaks almost nothing.

A small gap here is a measurement on this design, not a licence: with a member-specific input (a member’s own past winters, say) or transforms fit on fewer members, the same cell is where a member split earns its keep.

Try it: the tidier pipeline

A colleague fits the forced curve and the wet threshold on the whole table, test members included, before any split. Say what the held-out test in chapter 6 would then measure. Then read arm B’s line: is its gap distinguishable from the per-fold SD beside it?

Summary¶

The test members stay outside; validation folds are grouped by member and verified leak-free; the sibling check licenses taking the member as the unit. Scoring one model three ways turned the two leaks into numbers. Here they are small, and the lag-1 table and the one-input design say why.
