The held-out test, and the justification

This chapter scores chapter 2’s test members with the register’s final incumbent, reads the score against no skill, and writes the justification, for a model-world result: a test on observed winters would have to come before any briefing line. It is not a blind test: during development (2026-10-20) these same 20 test members were scored with the Niño-sign rule, with logistic and boosting at the base-rate threshold, and, in the companion course, with a small neural network (again on 2026-10-29). Boosting at the base-rate threshold was registered as this cookbook’s final model on 2026-10-29, after those scores had been seen, so the test members took part in choosing the model. Read the edge below as provisional.

The development scorings

Logistic at the base-rate threshold (precision − base rate +0.005, 95% interval over test members [-0.020, +0.028]: not distinguishable from no skill) and boosting at the base-rate threshold, the result below; the Niño-sign rule (its line under the test block); and a small neural network in the companion course (2026-10-20 and 2026-10-29). A fresh test would need data no choice was made on; chapter 7 uses the same members’ SSP3-7.0 winters.

Overview¶

  1. Rebuild chapter 5’s register and take its final incumbent.

  2. Run the held-out test once.

  3. Read it against no skill and count false alarms against hits.

  4. Justify the decision and state the limits.

Shared code lives in lensml.py beside the chapters.

The test¶

The final model is fit once on all training members and scored on the test members. Change anything after reading the score and the test members become a validation set, to be reported as such; set FINAL = False while adding trials. The 95% intervals resample whole test members, so they cover only which members were drawn, not the choice of model or chapter 5’s selection.

The switch, the counter, and what else the cell prints

FINAL ships True, so every build reruns and shows this test of the shipped register; re-running unchanged re-reads the same score. The run counter cannot see a restart; the discipline is yours. The cell also prints the wet-call share beside every recall, the false alarms and hits, and the three rung-0 lines on the same members; precision and AP are read against the base rate of the same test winters. The interval does not cover the training members either. A printed bound of ±0.000 reads NOT distinguishable.

FINAL = True  # the shipped register is final; set False while adding trials
if not FINAL:  # nothing reads the test labels
    print(
        f"test not run: set FINAL = True after your last trial (register so far: "
        f"{len(reg.rows)} tested rows, incumbent {reg.incumbent_name})"

else:
    TEST_RUNS = (
        globals().get("TEST_RUNS", 0) + 1
    )  # a second run in one session is a second test
    X_te, y_te = test[FEATURES].values, test["wet"].values
    final = reg.incumbent_make(RNG_SEED).fit(X_tr, y_tr)
    yhat_te = final.predict(X_te)

    tn, fp, fn, tp = (int(v) for v in cm_te.ravel())

    print(
        f"test run #{TEST_RUNS}"
        + ("" if TEST_RUNS == 1 else "   — NOT a test: report run #1")
    )
    print(
        f"final model: {reg.incumbent_name}   test members: {test.member_id.nunique()}   "
        f"test winters: {len(y_te)}   base rate: {y_te.mean():.3f}"

    acc_final = accuracy_score(y_te, yhat_te)
    print(
        f"precision (wet) = {precision_score(y_te, yhat_te, zero_division=0):.3f}   "
        f"recall (wet) = {recall_score(y_te, yhat_te, zero_division=0):.3f}   "
        f"wet-call share = {yhat_te.mean():.3f}   accuracy = {acc_final:.3f}   "
        f"AP = {average_precision_score(y_te, score_te):.3f}"
    )
    print(
        classification_report(
            y_te, yhat_te, target_names=["dry", "wet"], zero_division=0
        )
    )
    print(
        "test confusion matrix (rows = true, columns = predicted); the figure below "
        "draws the same matrix:"
    )
    print(
        pd.DataFrame(
            cm_te,
            index=["true dry", "true wet"],
            columns=["pred dry", "pred wet"],
        )
    )
    print(
        f"false alarms (true dry, called wet) {fp} · hits (true wet, called wet) {tp} · "
        f"false alarms per hit {fp / tp:.2f} · misses {fn} · correct rejections {tn}"

        f"costs less than hits / false alarms = {tp / fp:.2f} of a hit's value"

    base = y_te.mean()
    print(

            f"{name:11s} precision {precision_score(y_te, yb, zero_division=0):.3f}  "
            f"recall {recall_score(y_te, yb, zero_division=0):.3f}  "

    N_BOOT = 1000
    boot_rng = np.random.RandomState(RNG_SEED)
    member_rows = {
        m: np.flatnonzero(test["member_id"].values == m)
        for m in test["member_id"].unique()
    }
    names = list(member_rows)
    point = {
        "precision − base rate": precision_score(
            y_te, yhat_te, zero_division=0
        )
        - y_te.mean(),
        "AP − base rate": average_precision_score(y_te, score_te)
        - y_te.mean(),
    }
    draws = {k: [] for k in point}
    for _ in range(N_BOOT):
        picked = boot_rng.choice(names, size=len(names), replace=True)
        pick = np.concatenate([member_rows[m] for m in picked])
        yb, hb, sb = y_te[pick], yhat_te[pick], score_te[pick]
        draws["precision − base rate"].append(
            precision_score(yb, hb, zero_division=0) - yb.mean()

            average_precision_score(yb, sb) - yb.mean()

        lo, hi = (

        )  # as printed
        reading = (
            "above no skill"
            if lo > 0
            else (
                "below no skill"

                else "NOT distinguishable from no skill"

        )
        print(
            f"{reg.incumbent_name}: {k:22s} {point[k]:+.3f}   95% interval over test "

Justify the decision¶

Unidata’s closing instruction: “No matter your final decision, the most important aspect is your ability to justify it using data and a robust evaluation.”

The costlier error (chapter 4’s assumption) is a false alarm: “statistically wetter” in a briefing before a dry winter. Per the break-even line, saying “wetter” pays only if a false alarm costs less than the printed fraction of a hit; the always-wet's break-even line gives the same for calling every winter wet, and the gap is all the model adds. In this model world, an office that weighs a false alarm as heavily as a hit would gain nothing over CPC’s “equal chances”. The precision edge (the interval line) is small and provisional, and chapter 7’s test does not replicate it.

Why precision alone sets the false alarms per hit

False alarms per hit = (1 − precision) / precision, so any model with precision below 0.5 makes more false alarms than hits, however rarely it calls wet; the wet-call share only scales the two counts. The false alarms per hit line prints it.

The justification, in three labelled parts:

  1. Does it deliver? The interval, false-alarm and break-even lines.

  2. If not, say so plainly. The answer is the base rate; the briefing stays at “equal chances”.

  3. The next change, and its cost. A new season or box: a parameter edit and a rebuild (chapter 1). A new input: a new box mean in derive_member_winters and a rebuild (chapter 2). A snowfall target (PRECSC + PRECSL): one more derivation.

The result’s shape¶

The straight-line relation is indistinguishable from zero (chapter 2’s standard errors line). Training members’ wet rate varies between bins, extremes drier than the middle (chapter 2’s chi-square line). On the test members the chi-square line does not confirm it; the extremes minus middle line shows extremes drier again, a post hoc description, not a test. In chapter 7’s future winters only the coldest bin stands clearly below the base rate; the warm-end and middle pattern is not distinguishable from chance (its decile table; not a protocol outcome).

The NWS sign, read in two halves

The La Niña-dry half is stated for “the entire cold season”, and the coldest decile is below the base rate in the training members, the test members and chapter 7’s future winters (the decile tables), consistent with it; it is beyond 2 standard errors in the training and future winters only. The El Niño-wet half is stated “particularly during the late winter and spring of moderate to strong El Niños”, of which DJF holds only February, so it is barely tested here. Both are stated for east of the Divide; Boulder gives the north-central mountains the opposite sign (limit 7). The single highest training bin does not stand out again on the test members, and chapter 7’s protocol did not name the extremes contrast. Chapter 4’s coefficient agrees with chapter 2’s standard errors.

The limits¶

  1. A model world. CESM2 scored against CESM2, never observations: not the real Front Range.

  2. CESM2’s own ENSO and teleconnection, biases included.

  3. A ~1° grid, smoothing the orography Stagge et al. (2023) find amplifies the ENSO signal on western slopes.

  4. The season. DJF; NWS Boulder puts El Niño’s wet signal in “late winter and spring”, La Niña’s dry one in “the entire cold season”.

  5. Total precipitation (PRECC + PRECL), not snowfall, and a wet-only target: the coldest decile is below the base rate in all three samples (beyond 2 standard errors in two), a dry signal a classifier of wet winters cannot state as a “drier” call; a dry-tercile target is the next change to try.

  6. One forced-response curve for both forcing halves, so a half-specific forced path is absorbed, not tested. Rodgers et al. (2021, §2.3) report that the halves’ different biomass-burning forcing has “a discernible impact on large-scale climate”, including “tropical Pacific warming”, around 1990–2010; this cookbook does not test whether that shifts the Niño 3.4 input in those years.

  7. A box that crosses the Divide: about half mountain, half plains. NWS Boulder states the La Niña-dry sign for “southwest and eastern Colorado” in “moderate to strong La Niñas”, and the opposite for the “northwest and north central portions”, which the west column partly covers.

  8. Not a blind test (the top of this chapter).

The limits in detail

Limit 3: Stagge et al. (2023) find the amplification on the Intermountain West’s western slopes. Limit 4: the NWS wording is “particularly during the late winter and spring of moderate to strong El Niños”. Limit 6: the cmip6 and smbb halves share one curve and one threshold; their per-half base rates agree in chapter 2. Limit 7: the box’s west column (centre 106.25°W, edges 106.875–105.625°W) lies mostly on or west of the Continental Divide, and the middle column holds the foothills (Pikes Peak, 105.04°W 38.84°N, is inside it). Limit 8: the test members were scored with four models during development, and the final model was registered after.

Summary¶

The spine, end to end: framing, data, the forced response removed, a member split, a ladder, corrected paired trials, and a provisional held-out test read against the cost of a false alarm.
