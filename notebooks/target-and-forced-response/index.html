The target and the forced response

Every member of the ensemble follows the same forcing path by calendar year. Before a model can read ENSO, that shared path has to come out — fit on the training members only — and “wet” has to be defined against one threshold.

Overview¶

  1. Name the test members, per forcing half, before any statistic is fit.

  2. Remove the forced response with a curve fit on the training members only, and check the removal with a test that can fail.

  3. Define “wet” against one pooled threshold, and read the base rate per half.

  4. Look at the target against the input — the straight-line relation, and the wet rate by tenth of the input — and note the inputs not chosen.

Shared code lives in lensml.py beside the chapters (parameters, transforms, ladder, scoring, paired test, register); show() prints a function’s source where a chapter introduces it.

Remove the forced response¶

The raw SON Niño 3.4 box mean and the winter precipitation both carry a forced trend (Rodgers et al. 2021 §3.2; the check below prints each one’s correlation with year). A degree-FORCED_DEG polynomial in year, fit to the training-member ensemble mean, is subtracted from every member alike, leaving each member’s own departure from the shared path — the ENSO state, not the decade. Without it, the models would learn time-of-century and it would read as ENSO skill.

Then the target: wet = 1 when the detrended precipitation sits above the WET_QUANTILE of the pooled training members. One threshold for every member: a per-member quantile would fix each member’s base rate by construction, and the per-half check below could never fail. Curve and threshold are transforms fit on training members and applied to everyone else — as a StandardScaler inside a Pipeline is (scikit-learn’s Common pitfalls, §12.2.1) — written as two functions so that every validation fold in chapters 3–5 refits them. One curve is fit to both forcing halves together; the per-half check below is what licenses pooling them.

The check that can fail¶

A forced path the curve missed (too low a degree, a mid-century bump) survives the subtraction as decades whose mean anomaly sits away from zero. Each decade’s mean anomaly over the training members is divided by its standard error; the removal passes only if every decade of both series lies within ±DECADE_TOL standard errors. The correlation of the anomaly with year is not used: it is zero by construction for any FORCED_DEG >= 1, so it could never fail. The last line prints the chance that a correct removal trips the tolerance somewhere by luck.

DECADE_TOL = 3.0
d = table[is_train]
decade = (d["winter"] // 10) * 10
for anom, raw in ANOMALIES.items():
    r = d[raw].corr(d["winter"])
    print(
        f"corr({raw:20s}, year) = {r:+.3f}   "
        "(the forced trend in the raw series, training members)"
    )
removal_ok, n_tests = True, 0
for anom in ANOMALIES:
    g = d.groupby(decade)[anom]
    z = g.mean() / (d[anom].std() / np.sqrt(g.size()))
    worst = z.abs().idxmax()
    ok = bool((z.abs() <= DECADE_TOL).all())
    removal_ok &= ok
    n_tests += len(z)
    print(
        f"{anom:12s} decade-mean anomaly in standard errors: worst {z[worst]:+.2f} "
        f"(the {worst}s) · tolerance ±{DECADE_TOL:.0f} → {'PASS' if ok else 'FAIL'}"
    )
false_alarm = 1 - (1 - 2 * norm.sf(DECADE_TOL)) ** n_tests
verdict = (
    "PASS"
    if removal_ok
    else "FAIL — a forced path survived; change FORCED_DEG"
)
print(
    f"forced-response removal: {verdict}   ({n_tests} decade means; chance a "
    f"correct removal trips the tolerance somewhere ≈ {false_alarm:.0%})"
)
corr(nino34_son_K        , year) = +0.093   (the forced trend in the raw series, training members)

The base rate, per half¶

Read the base rate first. With WET_QUANTILE = 2/3 it sits near one third by design, so an accuracy near two thirds is what “always dry” scores — which is why this cookbook reports precision and recall against the base rate (scikit-learn’s Classification metrics guide). The two forcing halves share one threshold, so their base rates are free to differ: that is the check before pooling them. The cell then prints, per training member, the correlation of input and target, counts their signs, and divides the mean correlation by its standard error.

Reading the straight-line relation. NWS Boulder’s sign for east of the Divide is positive — warmer autumn Pacific, wetter winter — and stated for late winter and spring, not for the DJF season scored here. Read the per-member sign count line: do the members share a sign? Then the standard errors line under it: it says whether the mean correlation is distinguishable from zero. Stagge et al.'s two regional models set the observed context: “the North–Wyoming model explained 67.1% of winter precipitation” (a model bounded by 41.2° to 45.5° N) and “the South–Sonora dipole model explained less variance (34.5%)”. By latitude the Front Range falls in neither, but in the paper’s “transition zone (32–40° N)”, east of the “steep eastern slope” along which the northern signal “dissipates abruptly”; and in the northern pole the sign is reversed, with “increased winter precipitation during La Niña events”.

Read the chi-square line first: it says whether the wet rate differs between bins by more than chance, over the training members. Then the table: the coldest bin (the strongest La Niña autumns) and the warmest bins sit below the base rate, the middle bins above it — the extremes drier than the middle, a shape a straight line cannot follow, which is why the correlation reads near zero while the bins do not. Treat any single bin with care: with ten bins, one departure of a few standard errors can be luck. Chapter 6 applies these same edges to the test members to see which part of the shape repeats.

The one input, and the ones not chosen¶

One input was fixed because the question is about ENSO and a one-input model is one a scientist can read whole. The catalogue offers other monthly fields in both halves, each a fair input only as an autumn value, known before the winter starts.

Autumn (SON) fieldWhat it stands forHere
TS over NINO34the ENSO statethe one input (FEATURES)
PSL or Z3 over the North Pacifica stand-in for the autumn PNA statethe strongest next candidate
TREFHT over FRONT_RANGEthe box’s own autumn temperatureweaker: the box’s state, not the teleconnection
any field averaged over the winter monthsthe outcome’s own seasonnever: known only after the outcome
forcing_variantwhich half a member belongs tonot an input; the per-half check decides pooling

A new input means a new box mean in derive_member_winters and a rebuild, so it is a costed next change, never a quiet edit to FEATURES. NWS Pueblo’s outlook names PNA and NAO as the patterns with the “highest correlations wet/dry”.

Summary¶

Test members were named before anything was fit. The forced response was removed with a curve fit on the training members only, and a decade-by-decade check that can fail says whether it worked. “Wet” is one pooled threshold, so the per-half base rates are a real check. The straight-line relation is weak; over the training members the decile table shows a shape a line misses, which chapter 6 checks on the test members.
